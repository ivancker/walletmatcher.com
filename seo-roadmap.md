# WalletMatcher SEO Roadmap

This document tracks the SEO direction for WalletMatcher.

Website: https://walletmatcher.com/

## Main SEO Goal

The main SEO goal is to build WalletMatcher into a helpful hardware wallet comparison and recommendation website.

The site should rank for long-tail keywords around Ledger, Trezor, Tangem, cold wallets, hardware wallets, and beginner crypto self-custody.

## Primary SEO Positioning

WalletMatcher is not only a comparison website.

It is a wallet matching tool.

Core positioning:

> Find the best hardware wallet based on your needs.

This gives WalletMatcher a clearer angle than generic “best crypto wallet” articles.

## Technical SEO Checklist

Important checks:

- Sitemap works correctly
- Robots.txt does not block important pages
- Canonical tags are correct
- All main pages are indexable
- All pages have unique title tags
- All pages have unique meta descriptions
- H1 is unique on every page
- Internal links are crawlable
- Affiliate links use appropriate attributes
- Images have descriptive alt text
- Page speed is acceptable on mobile
- No important content is hidden from crawlers
- No duplicate thin pages

## Tracking Checklist

Track these events in GA4:

- page_view
- start_quiz
- quiz_complete
- result_ledger
- result_trezor
- result_tangem
- click_ledger
- click_trezor
- click_tangem
- click_affiliate_cta
- click_internal_compare
- click_quiz_from_blog
- click_wallet_logo

Important event parameters:

- page_path
- page_title
- wallet_name
- cta_text
- cta_location
- destination_url

## Internal Linking Plan

Every page should help users move deeper into the site.

Important internal linking patterns:

- Comparison pages should link to the quiz
- Guide pages should link to comparison pages
- Wallet-specific pages should link to related wallet comparisons
- Beginner pages should link to simple decision pages
- Bitcoin pages should link to long-term storage pages

Example:

- Ledger vs Trezor links to Ledger vs Trezor vs Tangem
- Tangem vs Ledger links to Card Wallet vs Hardware Wallet
- Best Cold Wallet for Bitcoin links to Best Hardware Wallet for Long-Term Storage
- Best Hardware Wallet for Beginners links to the homepage quiz

## Content Improvement Plan

Each SEO page should include:

- Clear H1
- Short answer near the top
- Comparison table
- Practical recommendation section
- Beginner-friendly explanation
- Internal links
- FAQ section
- Quiz CTA
- Affiliate disclosure where needed

## External Promotion Plan

Early traffic sources:

- Reddit comments
- Medium article
- Quora answers
- GitHub repository
- Social posts
- Niche crypto discussions

The goal is not to spam links.

The goal is to create useful entry points where people are already discussing hardware wallets.

## First SEO Milestones

### Milestone 1

- All core pages indexed
- Sitemap submitted
- GA4 tracking confirmed
- First external links added
- First impressions appear in Google Search Console

### Milestone 2

- 50 to 100 organic or referral users
- First affiliate CTA clicks
- Pages start showing impressions for long-tail keywords
- Improve titles and meta descriptions based on Search Console data

### Milestone 3

- Add more long-tail pages
- Improve comparison tables
- Add more visuals
- Strengthen internal links
- Improve pages with impressions but low CTR

## SEO Principle

WalletMatcher should win by being more useful, more specific, and easier to understand than generic wallet comparison articles.

The focus should be:

> Clear wallet recommendations based on real user needs.
